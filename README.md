## Présentation

**ALBA BADMINTON** est un site vitrine WordPress développé en PHP, destiné à présenter le **club de badminton de Lucé (28)**.  
Ce projet permet de centraliser les informations essentielles du club : inscriptions, horaires, actualités, photos et contacts.

Il repose sur un socle technique moderne combinant WordPress, PHP, JavaScript et des outils de gestion de dépendances comme Composer et npm.  
Des technologies comme **TailwindCSS**, **React**, **Next.js** peuvent être utilisées pour des modules dynamiques personnalisés.

## Démarrer le projet

### Pré-requis

Avant de commencer, assurez-vous de disposer des éléments suivants :

- PHP ≥ 8.0
- Composer installé : [https://getcomposer.org/](https://getcomposer.org/)
- Node.js & npm : [https://nodejs.org/](https://nodejs.org/)
- Un environnement serveur local (ex : XAMPP, WAMP, Laragon)
- Un serveur MySQL ou MariaDB (fourni dans la plupart des environnements)

### Installation

```bash
# Cloner le dépôt
git clone https://github.com/votre-utilisateur/alba_badminton.git

# Se rendre dans le dossier
cd alba_badminton

# Installer les dépendances PHP
composer install

# Installer les dépendances JavaScript (si thème personnalisé)
npm install
```

### Compilation des fichiers

Si vous utilisez un thème ou un composant personnalisé intégrant du JavaScript ou TailwindCSS, vous devrez compiler les fichiers sources.

Utilisez les commandes suivantes :

```bash
npm run dev    # Lance le serveur de développement avec watch
npm run build  # Compile les fichiers pour la production
```
